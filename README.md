# 和から環へ — 数学用語の練習帳

小学校の「和」から大学院の「層」まで、日本語の数学用語 **605 語** を、**定義・読み・英語・語源・存在理由** から学び、**実際に問題を解いて** 身につけるための静的ウェブサイトです。ビルド不要で、`index.html` を開くだけで動きます。

> **English summary** — *Wa kara Kan e* (“from sum to ring”) is a static study site for Japanese mathematical terminology, from elementary arithmetic to graduate mathematics. Each of the 605 terms has a definition, reading, English equivalent, etymology, an explanation of why the concept exists, links to learning resources and problems to solve. It includes type-in flashcard drills, an auto-graded problem set (expressions are evaluated, not string-matched), proofs with checked key steps, daily goals, streaks and spaced review. Everything runs in the browser; progress is stored only in the visitor’s `localStorage`. The in-site “このサイトについて” tab has a full English description.

## 機能

### 学ぶ
- **レベルの階段**：上部の 6 段（和・方程式・微分・写像・環・層）を押すと、その段階の解説・学ぶこと・記録・分野別の語数・まず押さえたい用語・問題集の単元が大きく開き、ほかのレベルはサイドバー（スマホでは横スクロールの列）に並びます。
- **用語集**：レベル・分野・覚えた／未習で絞り込み、漢字・読み・英語・定義で検索。各用語に定義・例・読み（ふりがな）・英語・注意（流儀の違い）・関連語。
- **なぜこの用語があるのか**：その概念がどんな問題を解くために必要とされたか。多くの用語に「歴史」（誰が・いつ導入したか）。
- **語源をチェック**：漢字一字ごとの音訓と意味（ウィクショナリーへのリンク）、原語（ラテン語・ギリシャ語・ドイツ語など）と日本語訳の歴史、深掘りリンク（Wikipedia 日英・コトバンク・MathWorld・nLab・J. Miller の語源辞典・MacTutor）。
- **この用語を学べるサイト**：[中学校数学・学習サイト](https://math.005net.com/)・[数学の景色](https://mathlandscape.com/)・[Math is Fun](https://www.mathsisfun.com/) の該当ページ。専用記事がない用語（Lv3 以上）には数学の景色のサイト内検索。
- **英語訳を隠す**：英語訳と、英語を使う問題をまとめて非表示にします。

### 解く
- **練習問題（フラッシュカード）**：すべて記述式。漢字→読み、定義→用語、語源→用語、日→英、英→日、実践問題、ミックス。範囲は全レベル・各レベル・間違えた用語・今日の復習。表記ゆれ（全角半角・カタカナひらがな・別表記・同義語）を吸収し、認める答えにない正答は「自分の答えも正しい」で自己判定できます。
- **問題集**：35 単元。
  - 算数：たし算・ひき算・かけ算・わり算（あまり）・四則の混じった計算・分数・小数・最大公約数と最小公倍数・割合と百分率・速さ
  - 中学：正負の数・一次方程式・一次不等式・連立方程式・展開・因数分解・平方根・二次方程式・一次関数の式
  - 高校：集合・二次不等式・判別式・虚数解・複素数・剰余の定理・多項式の割り算・解と係数の関係・二項定理・指数と対数・微分・定積分・数列と Σ
  - 大学：行列式・背理法（8 題）・数学的帰納法（8 題）。証明は要所の穴埋めを自動採点し、方針（ヒント）・模範解答・自己採点つき。
- **用語 ⇄ 問題集**：用語の詳細画面と練習問題の解答後にある「問題集で解く」で、その用語の問題（用語別の問題＋実践問題＋関連単元の生成問題）へ。問題集の各問題の「関連する用語」から用語の説明へ。問題集の一覧では用語名・読み・英語で問題を検索できます。

### 続ける
- **今日（ホーム）**：1 日の目標問題数と学習中のレベルを設定。達成状況・連続達成日数・連勝ストリーク・直近 7 日のグラフ・今日の名言。
- **これから復習（間隔反復）**：間違えた用語は 1 → 3 → 7 → 14 → 30 日の間隔で復習に戻り、最後まで正解すると定着として外れます。「復習」タブに予定表と誤答数順の一覧。
- **おすすめ**：期限の来た復習・正答率 70% 未満の苦手な単元・未挑戦の単元・まだ開いていない用語・証明問題（Lv4 以上）から最大 4 件。
- **連勝と名言**：正解ごとに連勝数、5・10・20… 連勝で通知。誤答のたびに数学者の名言（日本語訳・原文・出典。伝承は明記）。

### デザイン
- 方眼紙の上にフラクタル（シェルピンスキーの三角形・コッホ雪片・黄金螺旋・単位円）と、ゆっくり漂う数学記号の背景（canvas）。ライト／ダークの両テーマに対応。
- タブを切り替えると π の円が描かれ、円周率の数字が周りを回る演出。
- 戻る操作（ブラウザの戻る・「← 単元一覧」・「一覧に戻る」）では、コッホ雪片が反復を n = 5 → 0 と戻しながら逆回転。
- 答えには朱肉の判子：正解は丸印「正解」、不正解は角印「✕ 不正解」、5 連勝ごとに「大変よくできました」。

## 使い方・公開方法

### ローカルで開く
リポジトリを取得して `index.html` をブラウザで開くだけです。サーバーやビルドは不要です（Google Fonts を読み込めない環境ではシステムフォントで表示されます）。

### GitHub Pages で公開する
1. `main` ブランチに変更を取り込む。
2. リポジトリの **Settings → Pages** で、**Source: Deploy from a branch**、**Branch: `main` / `(root)`** を選んで保存。
3. 数分後に **https://alexandersaranich.github.io/WakaraKane/** で公開されます。

無料プランの GitHub Pages は公開リポジトリが対象です。Netlify・Cloudflare Pages・Vercel でも、ビルドコマンドなし・公開ディレクトリ `/` でそのまま公開できます。

## データの追加・修正

### 用語
用語は `TERMS` 配列のオブジェクトです（`data.js` は `T({...})`、追加ファイルは `E(id, 用語, 読み, 英語, 分野, 定義, 例, 語源, 注意, 関連語)`）。

| フィールド | 内容 |
|---|---|
| `id` | 一意な ASCII の ID（`#term-<id>` で直接開ける） |
| `t` / `r` | 用語 / 読み（ひらがな。カタカナ語の読みもひらがなで書く） |
| `en` | 英語。複数あるときは ` / ` で区切る（例：`injection / injective`） |
| `lv` / `f` | レベル（1–6）/ 分野（`FIELDS` のいずれか） |
| `d` / `ex` | 定義 / 例 |
| `ety` | 語源と訳語の歴史 |
| `note` | 注意（流儀の違い・読み間違いなど） |
| `rel` | 関連語の ID の配列 |

用語を追加したら、あわせて次も用意してください（`tools/check.js` が不足を報告します）。
- 用語に含まれる漢字の `kanji.js` への登録
- `motive*.js` の存在理由：`M(id, なぜ, 歴史)`（歴史は任意）
- 問題集の問題：`termprob.js` に追加するか、生成単元の `UNIT_TERMS`（`problems.js`）に ID を加える

### 問題
- **用語別の問題**（`termprob.js`）：`N`（数）・`X`（式）・`XE`（展開した式）・`S`（数の集合）・`P`（座標の組）・`I`（不等式）・`T`（語句）・`TS`（語句の集合）・`Y` / `Nn`（はい／いいえ）のヘルパーで書きます。数や式の答えは値で比較されるので、模範解答は計算できる形（例：`"36pi"`, `"sqrt(2)/2"`, `"1+i"`）で書きます。
- **実践問題**（`questions.js` ほか）：`{ lv, term, q, a: [認める答え…], e }`。順不同で全部答える問題は `set: [[同義の答え…], …]`。外国語の原語を問う問題には `en: 1`。
- **生成単元**（`problems.js` の `unit({...})`）：`gen()` が `{ q, type, a, show, e }` を返します。`type` は `num` / `expr` / `expand` / `factor` / `set` / `ineq` / `pair` / `qr` / `text` / `tset`。

### 学習サイトへのリンク
`sitelinks.js` は各サイトのサイトマップとページタイトルを照合し、手作業で確認したページだけを載せています（2026 年 11 月時点で全 462 ページが HTTP 200）。追加するときは、そのページが用語と同じ意味を扱っていることを確かめてください（例：Math is Fun の “field” は物理の場なので「体」には使わない）。

### チェック
```sh
node tools/check.js
```
ID の重複、関連語・各ファイルの ID の存在、漢字表、存在理由、全用語に問題があるか、読みがひらがなか、用意した模範解答と生成問題の答えが採点器で正解になるかを確かめます。

## 採点のしくみ
- 数や式の答えは**式として解析し、値で比較**します（複素数・多変数に対応。変数にいくつかの値を代入して比べる）。`x²+5x+6` と `6+5x+x^2`、`1±2i` と `1-2i, 1+2i` はどちらも正解です。
- 全角・半角、`−`（マイナス記号）、`²`、`√`、`π`、`≦`・`≧` などの表記ゆれを吸収します。「120円」「分速120m」のような単位・前置きも外して判定します。
- 形が問われる問題では形もチェックします：展開（かっこが残っていないか）、因数分解（積の形か・共通因数をくくり出したか）、√ の簡約、分母の有理化、小数の近似の禁止。値は合っていて形だけが違う場合は、誤答にせずヒントを出します。
- 集合・不等式の解（`x < 2, 3 < x`、`x ≠ 2`、`すべての実数`、`解なし` など）・座標の組・商とあまりにも対応します。不等式は境界付近の点で真偽を比べて判定します。

## 正確さと出典
- 定義は日本の大学数学で標準的な流儀に従い、流儀が分かれるもの（自然数に 0 を含むか、環に 1 を仮定するか、「体」が可換か など）は各用語の「注意」に書いています。
- 語源・歴史・名言のうち諸説あるものは「〜とされる」「伝承」「要旨」と明記しています。用語の標準は文部省『学術用語集 数学編』や日本数学会編『岩波 数学辞典』で確かめることをおすすめします。
- 誤りに気づいたら Issue でお知らせください。

## 記録とプライバシー
学習記録（覚えた用語・誤答・目標・連勝・復習の予定・言語の選択）は、ブラウザの `localStorage` だけに保存されます。学習記録がサーバーに送られることはなく、別の端末・別のブラウザ・別のドメインとは共有されません。「復習」タブの「学習記録を消去」で用語の記録を消せます。

外部への通信は Google Fonts（`fonts.googleapis.com` / `fonts.gstatic.com`）からのフォントの取得だけです。このとき閲覧者の IP アドレスなどが Google に送られます（アクセス解析・広告・Cookie は使っていません）。EU の利用者が多い場合など、この通信をなくしたいときは、フォントを自分のサーバーに置く（OFL で再配布可）か、`index.html` の Google Fonts の `<link>` を削除してシステムフォントで表示してください。

## アクセシビリティ
- ライト／ダークの両テーマ、スマートフォン幅（約 390px）に対応。
- OS の「視差効果を減らす」（`prefers-reduced-motion`）が有効なときは、背景を静止させ、π とコッホ雪片の演出を省き、判子をアニメーションなしで表示します。
- 演出用の要素は `aria-hidden`。入力欄・ボタンにはラベルとキーボードのフォーカス表示があります。
